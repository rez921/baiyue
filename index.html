已經架好網站了？3 步驟「上傳覆蓋」舊版 index.html

⚠️ Mac 電腦最重要提醒：檢查檔名不能有 (1)

當您在 Mac 下載第 2 次 index.html 時，「下載項目」資料夾裡可能會自動變成 index (1).html 或 index-2.html。
請先去「下載項目」把舊的刪掉，確保新檔案名稱一字不差叫做 index.html，上傳時 GitHub 才會自動覆蓋舊檔！

方式 A：拖曳上傳直接覆蓋（最簡單）
  1. 打開您的 GitHub 儲存庫頁面（例如 github.com/您的帳號/baiyue）。
  2. 點擊右上角的 「Add file」 按鈕 ➔ 選擇 「Upload files」。
  3. 把剛剛下載且確認檔名為 index.html 的檔案拖曳進框框（只要檔名相同，GitHub 會自動取代舊檔）。
  4. 滑到最下方點擊綠色按鈕 「Commit changes」，等 1 分鐘即更新完成！
方式 B：直接貼上原始碼覆蓋（不怕檔名搞錯）
  1. 點擊上方 「複製完整原始碼」 按鈕。
  2. 去您的 GitHub 儲存庫，點開原本的 index.html，再點右上角的 「✏️ 鉛筆圖示 (Edit this file)」。
  3. 在程式碼畫面按 Cmd + A（全選）並刪除，再按 Cmd + V（貼上新版程式碼）。
  4. 點擊右上角綠色 「Commit changes...」 確認儲存即可！

方法一：免設定 Token！5 步驟手動上傳 GitHub 架站 (約 3 分鐘)

STEP 1 // 下載網頁單一檔案 (`index.html`)

點擊右上角黃色按鈕 「第一步：點此下載 index.html」 將檔案存到電腦或手機。
⚠️ 注意：檔名必須保持為小寫 index.html（若變成 index (1).html 請改回 index.html，因為 GitHub 預設會抓取 index.html 作為首頁）。

STEP 2 // 建立 GitHub 公開儲存庫 (New Repository)

1. 登入 https://github.com/new ↗（若無帳號請先免費註冊）。
2. 在 Repository name 欄位輸入英文名稱，例如：baiyue。
3. 下方權限請務必維持預設的 Public (公開)（免費版 GitHub Pages 僅支援 Public）。
4. 滑到最下方點擊綠色按鈕 Create repository。

STEP 3 // 把 `index.html` 拖曳上傳並儲存

1. 建立完成後，在畫面中間找到藍字連結 uploading an existing file 點進去（若您有勾選 README，則是點右上角 Add file → Upload files）。
2. 將剛剛下載的 index.html 直接拖曳進畫面中央虛線框（或點 choose your files 選取檔案）。
3. 等待 2 秒看到 index.html 出現在清單後，往下滑點擊綠色按鈕 Commit changes。

STEP 4 // 開啟 GitHub Pages 免費網頁開關

1. 點擊儲存庫最上方選單列最右邊的 ⚙️ Settings（設定）。
2. 在左側選單往下找，點擊 Pages。
3. 在中間 Build and deployment → Branch 下方，把原本顯示 None 的下拉選單改選為 main（或 master），旁邊維持 / (root)，然後按下 Save。

STEP 5 // 大功告成！取得您的專屬網址 & 加入手機桌面

按下 Save 後等待約 60 秒，重新整理該頁面，上方就會出現：
Your site is live at https://您的GitHub帳號.github.io/baiyue/
• iPhone 變成 App 圖示：用 Safari 打開網址 → 點底部「分享」圖示 → 點「加入主畫面」。
• Android 變成 App 圖示：用 Chrome 打開網址 → 點右上角「⋮」→ 點「加到主畫面」。
